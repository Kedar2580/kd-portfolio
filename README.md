# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Kedar2580/kd-portfolio.git
```

Move into the project directory

```bash
cd kd-portfolio
```

Install Dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Build for Production

```bash
npm run build
```
